# epicycloids_drawing

These algorithms simulate circles-generated epicycloids we sometimes see on social media. A closed continuous curve on the complex plane can be described as a limit of epicycloids according to Fourier's analysis. The code is divided in three files. The first one takes as input the reference of the picture we want to plot with epicycloids. We are supposed to click along the figure as many times as possible and we get the list of coordinates for each point. Previously I wanted to code a much user-friendly option by darker pixel recognition but I made some tests and I could not get a satisfying result without mistakes. Afterwards the second file takes as input the list of coordinates and computes radius and phase at origin circles with complex integral formulas given by the Fourier’s theory. The list is considered as a sample of the continuous curve and integrals are computed with a rectangle method. I did not know there were special packages for that. The last part of the code takes as input radius and phase at origin circles and animates the draw of the original figure with Matplotlib.
